The Greenwold: every structure to make

Read off the spaces that stand them, the guide's zone lists, the footprint table and the folder of finished models, so the list is what the world asks for and not a memory of it.

86 distinct structures across 131 spaces: 85 made, 1 to make. Generated 2026-09-07. Sizes are the base library footprint, width by depth by height in metres. Each placed piece multiplies those dimensions by its saved scale; the authored settlement buildings currently use 1.25. A structure not made yet stands in the game as a stand-in body of its footprint.

Studio production: 85 of 86 complete. Detailed Three.js models in Brackenwake studio, with front, side, back, top and perspective review and metre-scale GLB export. Game import is tracked separately. Studio models may exceed the MMO's runtime triangle budgets and need optimization before game import.

Each section is one zone in the order the first hour meets them. A structure is listed under the first zone that needs it and named again where it recurs. The spec every model is built to (glb, metres, Y up, budgets by height, the validator) is in docs/concepts/greenwold/MODELS.md.
