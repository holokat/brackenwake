NOSTRUX HOMESTEAD — SOUND EFFECTS TO GENERATE
=============================================

Every entry below is an event the game ALREADY FIRES. Nothing here needs new
gameplay — the hook exists, it is either silent or borrowing the wrong sound.

Format for a generator: the PROMPT line is what to paste. Length and notes
follow. All mono, 44.1kHz. Aim for a dry recording with almost no reverb tail —
the game has no reverb bus, and a wet sample sticks out the moment two overlap.

Style target across the whole set: warm, close-miked, slightly chunky. Real
materials, not synth. Nothing cartoon, nothing cinematic, no musical stings, no
riser/whoosh design. The visual language is flat-shaded low-poly, so the audio
should be plain and physical rather than glossy.

NOTES
================================================================

MULTIPLE TAKES: anything that fires more than once in quick succession needs
3 takes minimum (axe, pickaxe, harvest). The rotation code already exists —
`audio.playSfxVariant(base, count, vol, ambient)` in audio.js walks a reshuffled
cycle and never repeats back to back. Name files `<base>-1.mp3`, `<base>-2.mp3`
and it works with no further wiring.

AMBIENT FLAG: any world sound (weather, birds, owls, wind) must be played with
`ambient = true`. Sound effects double as the "player is busy" signal that
steers the music rotation, so a bird call over an empty farm would otherwise
swing the soundtrack to the lively track.

LOOPS: rain, storm and reeling must loop seamlessly — no fade at either end,
and the last frame has to meet the first. Everything else is one-shot.

FORMAT: mono mp3, 96kbps, 44.1kHz for one-shots. Stereo for the weather beds
only. Drop them in public/audio/sfx/ and register the extension in the SFX_EXT
map in audio.js.

LEVELS: record hot and let the game attenuate. Every call passes an explicit
volume, and the world sounds sit at 0.15-0.35 against music at 0.35.

WHAT NOT TO MAKE: footsteps (there is no player avatar), UI hover sounds (the
build menu would chatter), voice or vocalisations of any kind, musical stings
on success, and anything with a designed riser or whoosh.
