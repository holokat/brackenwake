Wave A, M2. Owned files: `src/mmo/monsters.js`, `src/mmo/monsters.test.mjs`,
`docs/mmo/05-WORLD-CONTENT.md`, this note.

What landed as data: forty new monster rows, twelve named bosses, a body family
and a modelling note on every one of them, ten tamable animals, eighty three
per place rosters keyed by `src/mmo/realms.js` place ids, and an audit that
throws at load on any of it going wrong. The roster went from 48 rows to 100.

Nothing outside those four files was touched. What has to be done in files this
agent does not own is written out here in full, so each of them is a paste and
not a design job: the bodies (section 1, already done by that file's owner in
the same wave), the rule behind each new tag (section 2), the systems that do
not exist yet (section 3), and four checks in other suites that count the
roster and now count it wrong (section 4).

## 1. Bodies: `src/game/monster_models.js`, already done, and how

`auditMonsterShapes()` throws at load for every monster above tier 0 with no
silhouette, so the forty eight new rows above tier 0 would have taken that file
down and `src/game/monsters.js` with it. Every wave A row therefore carries the
family it borrows in a field called `family`, audited at load against the
builder table read out of `monster_models.js` itself.

**Measured on the working tree as this note was written: that file's owner has
already added the rule, and it is exactly the fallback this field was written
for:**

```js
export function shapeFor(id) {
  const m = MONSTERS[id];
  if (!m) return null;
  if (m.tier === 0) return null;
  if (SHAPE_FOR[id]) return SHAPE_FOR[id];
  return m.family && BUILDERS[m.family] ? m.family : null;
}
```

## 2. The tags added this wave, and the rule each one needs

Twenty one tags were added to `NOTE_TAG_MEANING` in `src/mmo/monsters.js`. Five
of them are already acted on by code that exists; the rest need a rule, and
until they have one **the row still fights**, because no row carries only new
tags. The audit and `monsters.test.mjs` prove the last part.

Already wired, nothing to do:

| tag | wired where |
| --- | --- |
| `bow` | `monster_ai.RANGED_TAGS` already maps it to the `shot` mode, and says in its own header that it is listed for exactly this day. The Legion Archer and Huntmaster Gallow shoot today. |
| `shield` | the row's AR already holds it; it is descriptive |
| `fireImmune` | needs one line, see below. Every row carrying it also carries a working tag |
| `huge` | read by `auditMonsters` only: it exempts a tier 0 row from the document's 1 to 8 health |
| `dummy` | the training yard's bodies (IS2, 2026-09-08): game/monsters.js `spawn` sets `still` and `trainsTo`, `stepMonster` returns at once for a still body, the critter bolt skips it, `standBackUp` rights it instead of `died`; combat.js `teach` refuses a weapon lesson past `trainsTo` and says so once; monster_models.js builds it from training_models.js and the poser only rocks it when hit |
| `wanders`, `noonOnly` | read by the events layer (E2), not by combat. `route` is on the row |

Needing a rule. Each is written against the file it belongs in.

### `fireImmune` (src/game/actor.js, one line)

`NOTE_RESISTS` already turns `immunePoison` and `coldImmune` into resists at
`RESIST_CAP`. Add the third:

```js
const NOTE_RESISTS = {
  immunePoison: ['poison', RESIST_CAP],
  coldImmune: ['cold', RESIST_CAP],
  fireImmune: ['fire', RESIST_CAP],
  incorporeal50: ['physical', 50],
};
```

Carried by: Ember Drake, Cinder Imp, Lava Hound, Glass Wyvern.

### `summons` (src/game/monsters.js)

The row carries `summons: { id, count }`, audited to be a real row of a lower
tier. `monsters.js` already has a summon for bosses: `stepBoss` runs a phase of
kind `summon` and `SUMMON_COUNT` / `SUMMON_RING_M` are already imported. The
rule:

- a boss phase of kind `summon` spawns `row.summons.count` of `row.summons.id`
  in a ring of `SUMMON_RING_M` around it, rather than `SUMMON_COUNT` of a
  hardcoded id;
- a row that is not a boss and carries `summons` does it once, the first time
  it drops below half health, and says so;
- the summoned monsters count against `ALIVE_CAP` and are cleaned up with their
  summoner's group, not left standing.

### `shieldWall` (src/game/monsters.js)

While two or more live monsters of the same row stand within 4 m of each other,
each gains +10 AR. Recomputed on the same sweep that already groups a pack; it
must come off when the second one dies, and the plate or the floater has to say
it is on, or it is a silent effect. Carried by: Legion Soldier, Legion Knight,
Drowned Marine, Legate Ossory.

### `healsAllies` (src/game/monsters.js)

A cast, using the caster path that already exists: `attackModeOf` gives the
Legion Chaplain `cast` because it also carries `casts`, so the hold and the
interrupt are free. On the cast landing, heal every ally within 8 m by the
row's own damage range rather than damaging the player. Say it: "the chaplain
lifts the cup, and the wall closes up". Carried by: Legion Chaplain.

### `howl` (src/game/monsters.js)

On first taking damage, pull every monster of the same row within 30 m into the
fight, once. This is `sharesAggro` with a bigger radius and a line, and it
should say the line. Carried by: Bone Hound, Huntmaster Gallow, Rimemouth.

### `dives` (src/game/monsters.js)

A flyer at `hoverHeight` that is more than 8 m from its target drops to
`approachHeight` over `SWOOP_SECONDS`, lands one blow at double damage, and
climbs again. `SWOOP_SECONDS` is already imported. Carried by: Hawk, Canopy
Harpy, Storm Wyvern, Glass Wyvern.

### `grab` (src/game/monsters.js)

On a landed blow, one in four: root the target for 3 s and deal the row's low
damage each second while it holds. Broken by killing the holder. It is
`webRoot2` with damage on it and it should reuse that root. Carried by: Salt
Crab, Sandworm, Kraken, Sea Wyrm, Thalassa.

### `ambush` (src/game/monsters.js and the spawn)

Spawns hidden: no name plate, no model, no aggro, until a target comes within
6 m. Then it appears, aggros, and its first blow is doubled. Carried by: Reed
Stalker, Cairn Wight, Reef Eel.

### `awakens` (src/game/monsters.js)

Aggro radius is 0 until a target comes within 4 m, then it is the row's own.
The difference from `ambush` is that it is visible the whole time: a statue you
have already walked past. Carried by: Temple Guardian.

### `burrows` (src/game/monsters.js)

Every 12 s while alive and further than 5 m from its target: sink, vanish for
2 s, and come up within 3 m of the target. It must not come up inside geometry
and it must not break the leash. Carried by: Sandworm.

### `dropsFromAbove` (src/game/monsters.js and the spawn)

Spawns 6 m up and stationary. When a target passes under it, it drops, taking
no fall damage, and fights normally from there. Carried by: Blossom Spider.

### `stormCall` (src/game/monsters.js)

A ranged ability that is not a projectile: mark the ground under the target,
wait 1.5 s, then hit everything within 3 m of the mark for the row's damage as
`energy`. It needs an entry in `monster_ai.RANGED_TAGS` (`stormCall: 'cast'`)
and a spell in `spellFor` with `damageType: 'energy'` and no cone. Carried by:
Reef Eel, Storm Wyvern.

### `powderCharge` (src/game/monsters.js)

Thrown, on a 10 s cooldown: a charge lands at the target's feet and goes off
2 s later for the row's damage as `fire` within 3 m, moving whatever it hits.
`RANGED_TAGS` entry: `powderCharge: 'thrown'`. Carried by: Legion Sapper.

### `hex` (src/game/monsters.js)

The document's own "casts Fireball and Hex". A second cast on a 15 s cooldown
that lowers the target's hit by 15 for 10 s and says so on the floater.
Carried by: Cultist Adept, Fen Witch, the Librarian.

### `ashCloud` (src/game/monsters.js)

On a landed blow: the target's hit falls by 20 for 6 s, and the screen should
say why. Carried by: Rider Wraith, Ash Wraith.

### `tailSweep` (src/game/monsters.js)

Every fourth swing is a cone rather than a target: `coneTargets` at 4 m and
90 degrees, the row's damage to everything in it. `coneTargets` already exists
and is already imported. Carried by: Sandworm, Kraken, Thalassa.

### `dragonTime` (src/game/monsters.js)

Malachar, and nothing else, ever. His swing timer runs at half its seconds and
his approach at 1.5x speed while above 33% health; below it, the world slows
instead and the player's own swing timer is what stretches. It is the one
ability in the game that is allowed to touch the player's clock, and it is the
last boss.

Animal Taming's own 0 to 100, each fed on a real `items.js` base. There is a

`wanders` tag. `BOSS_BY_LAIR` gives the other ten their room. The events layer
(E2 in the programme) is what walks a route; until it exists both of them spawn
in their lair like the other ten, which is honest and dull.

boar is. That list is printed by `monsters.test.mjs` on every run, grouped by
family, which is the modelling queue in the order it costs the most.

## 4. Four checks in other suites that hardcode the old roster

Adding rows moves numbers that three test files had written down as literals.
None of them is a bug in the thing being tested; each is a count that was true
of 48 rows and is not true of 100. They are in files this agent does not own,
and their owners were editing them while this landed, so they are written out
here rather than changed.

Measured: `src/game/monsters.test.mjs` went from 8 failures to 15 with the new
rows in, and `src/game/skinning.test.mjs` from 0 to 1. Of that, four of the
seven new failures in `monsters.test.mjs` are a tier 0 check that was ALREADY
failing before this wave, for F1's reason and not this one (see the fourth item).

**a. `src/game/monsters.test.mjs:352`, the meadow roster.** The Kingsroad is the
Legion's road, so the meadow now spawns Legion soldiers, archers and raiders by
day. The check wants the document's four to still be there rather than to be
all there is:

```js
  check('the meadow by day still holds rats, boars, bandits and goblin scouts',
    ['bandit', 'boar', 'giantRat', 'goblinScout'].every((id) => dayIds.has(id)), [...dayIds].join(', '));
```

**b. `src/game/monsters.test.mjs:722`, "eight rows attack at range".** Now
twenty five, because the Legion has archers and the world has casters. The
honest form is the one that cannot go stale:

```js
  check('every row that attacks at range says so in a tag', ranged.every((id) =>
    MONSTERS[id].notes.some((n) => RANGED_TAGS[n])), `${ranged.length} rows: ${ranged.join(', ')}`);
```

**c. `src/game/monsters.test.mjs:838`, "four rows fly".** Now eleven:

```js
  check('every flyer carries the flying tag or the flying kind', flyers.every((id) =>
    MONSTERS[id].notes.includes('flying') || MONSTERS[id].kind === 'flying'),
    `${flyers.length} rows: ${flyers.join(', ')}`);
```

**d. The tier 0 model checks, already fixed while this landed.** Between the
first and last runs of this wave, that suite's owner rewrote the tier 0 model
checks for F1's critter bodies, so the four silent failures wave A's tier 0 rows
were adding are gone. Nothing to do; recorded because the numbers in this note
were measured on both sides of it.

**e. `src/game/skinning.test.mjs:70`, "29 of them carry a hide word".** Now 52:

```js
  check('every row that can be skinned carries exactly one hide word',
    a.skinnable === Object.values(MONSTERS).filter((m) => skinWordFor(m)).length,
    `${a.skinnable} of ${a.rows} rows: ${JSON.stringify(a.byWord)}`);
```

**f. `src/game/win_dev.test.mjs:887`, a rarity tolerance on its boundary.**
`rollLoot({ tier: 5, count: 2000 })` spreads its two thousand rolls over every
tier 5 row, and there are eleven of them now rather than six, so the sample per
row changed. The measured worst deviation from `weightsFor(5, 0)` is 8.0 points
against a bound of `worst < 8`: it is sampling noise sitting exactly on the
line, not a change in the weights. The honest fix is a larger sample or a bound
that is not a tie:

```js
  const r = bench.rollLoot({ tier: 5, count: 8000, seed: 99 });   // was 2000
```
